<p>同一份报价单，三个人算出来的月成本能差一倍。原因不在算术，而在单位：按月报的是「条」，按流量报的是「GB」，按并发报的是「连接」。三个单位换算不到同一个尺子上，比价就没有意义。这篇把三种计费口径逐个拆开，换成同一种算法，再放到一张年账单上，让你看清自己这个规模到底该选哪种。所有价格都是区间举例，仅供参考。</p>

<h2>一、先把三种单价换成同一把尺子</h2>
<p>换算的关键是找出你一个月到底消耗多少。先做一个粗测：连续三天记录每天的会话数和下载量，取平均再乘三十。会话数决定并发，下载量决定流量，账号数决定要几条独享出口。三个数出来之后，任何报价都能换算成「每月总支出」这一个指标。</p>
<h3>换算公式与常见区间</h3>
<p>按月的支出等于单价乘条数；按流量的支出等于单价乘 GB 数；按并发的支出等于单价乘并发数。三者的单价区间大致是：独享静态出口每条每月两百到六百元；住宅流量每 GB 二十五到六十元；并发每个每月五十到两百元。差距很大，所以一定要换算之后再比。换算表如下。</p>

<h2>二、按月计费：固定支出里还藏着什么</h2>
<p>按月是最容易预算的一种，也是最容易被「闲置」吃掉钱的一种。三条出口，实际只用到两条，第三条照样收费。所以按月计费的核心不是单价，而是你的出口利用率。利用率低于六成，说明买多了。</p>
<h3>年付折扣的账要倒着算</h3>
<p>年付常见打八折到九折，看上去划算，但要算两件事：一是这笔钱占用多久，二是中途换服务商的沉没成本。如果账号周期本来就只有半年，年付等于把风险提前买下来。稳妥的做法是首年走月付，确认线路稳了再谈年付，并且要求年付也能按月折算退款。</p>
<h3>闲置月的处理方式</h3>
<p>有些服务商支持按月暂停并保留配置，暂停期收少量保留费，一般是原价的百分之十到三十。做季节性业务的话，这个条款比折扣更值钱。问清楚暂停期间地址会不会变，变了等于没保留。</p>

<h2>三、按流量计费：对话场景的真实消耗</h2>
<img src="/tp.png" alt="统计住宅IP月流量消耗与计费换算的表格界面">
<p>对话类使用听起来很轻，实际消耗常被低估。一次普通问答的上下行加起来通常只有几百 KB 到两三 MB，真正吃流量的是三样东西：上传长文档、生成图片或附件下载、以及页面上的静态资源反复加载。前者一次性几十 MB，后两者会持续累积。</p>
<h3>单次对话大概吃多少流量</h3>
<p>纯文本问答按每次一到三 MB 估，一天五十次就是五十到一百五十 MB，一个月不到五 GB。这个量级下按流量计费很便宜。但如果每天上传几份 PDF、再下载生成的表格，日消耗可能冲到几百 MB，一个月十几 GB，成本立刻反超按月计费。</p>
<h3>图片和长文档为什么贵</h3>
<p>图片是按原始体积传输的，一张手机照片就有三到八 MB，一次传十张就是几十 MB。长文档如果反复重传同一个文件，流量会重复计。省的办法是在本地先压缩、先合并，再上传一次，而不是分十次传。</p>

<h2>四、按并发计费：人数、连接数和端口数别混</h2>
<p>并发是这三个词里最容易被偷换概念的。销售说的并发，可能指同时在线的人数，也可能指同时建立的 TCP 连接数。一个浏览器标签页就能开出几十条连接，一个人同时开五个标签，按连接数算就爆了。签之前必须问：并发按什么计数，超了是限速、排队还是额外计费。</p>
<h3>并发数怎么估才不浪费</h3>
<p>实测方法很简单：在业务最忙的半小时内，让所有使用者同时操作，然后在服务商后台看并发峰值，取这个峰值的 1.2 倍作为采购量。不要按人数乘系数拍脑袋，人少但都开多标签的情况很常见。</p>

<h3>什么规模会翻转结论</h3>
<p>拐点通常在两个地方。一是账号数超过十条，按月计费的固定成本开始压过流量计费；二是月流量超过五十 GB，流量计费的单位成本会迅速追上按月。把自己的两个数字放进上面这张表，答案基本就出来了。</p>

<h2>常见问答</h2>
<h3>流量计费是只算下行还是上下行都算？</h3>
<p>答：两种都有，必须在合同里确认。上传长文档多的话，上下行合计会比只算下行高出一大截，采购前按最严的口径估预算更安全。</p>
<h3>按月计费能不能中途加一条出口？</h3>
<p>答：多数可以，但加购价往往高于首单价，而且可能要求补齐剩余周期。加之前问清加购单价和生效时间，别默认和首单同价。</p>
<h3>并发被限之后，表现是什么样？</h3>
<p>答：常见是新建连接被拒或排队，表现为页面转圈、接口超时。看服务商后台的连接数曲线能确认，如果是自己程序没关连接，先修代码比加钱更有效。</p>
<h3>三种口径可以混着买吗？</h3>
<p>答：可以，常见组合是主账号按月独享、临时任务走流量包。混买的关键是把账目分开记，否则月底根本算不清哪部分超了。</p>

<h2>合规提示</h2>
<p>文中所有价格均为市场常见区间的举例，标注「仅供参考」，实际费用以服务商合同、发票与工单约定为准，不同地区、不同线路质量差异较大。</p>
<p>采购网络服务应选择具备合法经营资质的主体，并按实际业务需求申报用途。以虚构业务、隐瞒真实用途的方式获取低价资源，可能带来合同与合规风险。</p>
<p>预算测算涉及企业真实数据时，请注意内部数据管理规范，避免把账号、流量等敏感信息散落在个人设备或公共表格中。</p>
